# Architecture decision records

One file per decision, numbered in the order they were settled.
Records 0001 to 0013 were settled while the plugin was still a package inside the first project that used it.
Records from 0014 on were made after it became the standalone `pytest-xharness-eval` package.

A record's argument is never edited once accepted.
When a later record supersedes or refines an earlier one, the edge is declared on both records.
A reader who lands on an old record is therefore pointed forward, and the table below carries the same links.
Every record opens with its **Lens**: the reusable rule it leaves behind.
