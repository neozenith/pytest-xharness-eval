# GOAL

> Given I have code that functionally achieves the stated goal, how do I measure how easy it is to review and understand the code?

- What are the factors leading to increased cognitive load to read, understand and maintain code?
- How can we measure that?
- How can we curate a balanced scorecard of measures so no single metric is gameable?
- How can we equally score an entire code base in the same way we score just a subset in a Pull Request?
- How can we easily use the same deterministic tooling to score any codebase regardless of language?
