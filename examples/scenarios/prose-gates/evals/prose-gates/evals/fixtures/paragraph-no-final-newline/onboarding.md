# Onboarding

New contributors clone the repository and run the install target.  
The install target syncs the Python tools with uv.   
It then installs the Bun dependencies into node_modules.
A fresh clone needs no other setup before its first build.
Every change lands through a pull request against main.
A reviewer reads the diff and the decision records it cites. 
The pull request merges once both checks pass on its latest commit.  
Nobody pushes to main directly, not even a maintainer.
